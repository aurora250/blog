# 关于我

你好，我是 **Aurora**。这里是用来记录、整理与分享的个人空间。

> 这个页面放在 `src/content/spec/about.md`，直接编辑这个文件即可替换成你自己的介绍。

## 这里会写什么

- **技术笔记**：踩过的坑、想明白的设计、值得留下的代码片段
- **随笔记录**：日常的思考与阶段性的总结
- **项目复盘**：做过的东西，以及当时的取舍

## 关于这个站点

站点使用 [Astro](https://astro.build/) 构建的 [Shirone](https://github.com/LyraVoid/Shirone) 主题，
通过 GitHub Actions 自动构建并发布到 GitHub Pages —— 每次 push 到 `main` 分支就会自动重新部署。
