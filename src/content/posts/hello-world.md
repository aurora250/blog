站点正式上线了。这个博客用来存放一些平时想留下来、但又不适合发在聊天窗口里的东西。

## 打算写什么

- **技术笔记**：踩过的坑、读代码时的发现、值得复用的实现思路
- **项目复盘**：做过的东西，当时为什么这么取舍，后来看对不对
- **随笔**：阶段性的整理，以及一些没处放的念头

写作目标很简单：**把想清楚的事情写下来**。写不清楚，说明其实还没想清楚。

## 这个站点是怎么跑起来的

整个站点是纯静态的：

1. 文章以 Markdown 放在 `src/content/posts/`；
2. 推送到 GitHub 的 `main` 分支；
3. GitHub Actions 自动执行构建，把产物发布到 GitHub Pages。

也就是说，写文章只需要做一件事：新增一个 `.md` 文件，然后 push。

```bash
# 新建文章（会自动带上 frontmatter）
pnpm new-post my-post

# 本地预览
pnpm dev
```
